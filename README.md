# work_doc · 鲁班猫开发板问题速查库

记录在鲁班猫（LubanCat）系列开发板上做系统移植、驱动适配、外设调试、AI 应用时遇到的问题与解法。
**按「功能域」组织，不按文件格式组织**——同一主题的 md 与 pdf 同名并列，取你需要的格式即可。

- 想快速定位：看下面的「文档索引」，按分类找现象。
- 想了解规则：看 [`00-规范与索引/分类方案.md`](00-规范与索引/分类方案.md)（分类依据、命名规范、新增资料如何归档）。
- 手上有新资料：先读分类方案第八章的决策流程，再落位。

| 目录 | 收录内容 |
|---|---|
| `01-镜像与构建/` | 烧录、备份还原、分区、SDK/buildroot 编译、发行版与异平台适配 |

| `05-网络与远程/` | 联网与共享、SSH/VNC/xrdp/投屏 |
| `06-应用与AI/` | Qt 工具链、AI 环境与例程、视频流推流、容器 |

## 资源与附件

## 新增资料怎么放

见 [`00-规范与索引/分类方案.md`](00-规范与索引/分类方案.md) 第六至八章：
1. 先判断是文档还是附件（附件进 `_assets/` 或 `_pkg/`）；
2. 用一句话写清"解决了哪个功能域的问题"，据此选一级目录；
3. 子类不足 4 篇就不要新建子类，直接平铺；
4. 同一主题已有文档时追加章节，不新建文件；跨域时只放一处，另一处加链接。
